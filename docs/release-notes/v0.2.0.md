# RPGCreator `v0.2.0` (Experimental Test Release)

> [!WARNING]
> **실험 단계 테스트 버전 안내**
>
> 본 릴리즈(`v0.2.0`)는 **초기 실험용 테스트 버전**입니다. 일부 에디터 기능, mruby RGSS 스크립트 호환성, 외부 프로젝트 변환(`MV/MZ`, `VX Ace`, `Tiled`), UI 동작에서 예기치 못한 문제가 발생할 수 있으며 향후 업데이트 과정에서 호환성이나 옵션이 변경될 수 있습니다. 기존 프로젝트 테스트 전 반드시 원본 백업을 보관해 주세요.

## 자체 mruby 4.0 VM · RGSS1/RGSS3 동시 지원 · 사용자 RTP 분리 로더

### 새 기능 및 개선 사항
- **자체 네이티브 Ruby VM (`native/rpgc_mruby.dll`)**: MIT 라이선스 공식 `mruby 4.0.0` C VM을 x64 MSVC DLL로 내장해, 외부 Ruby 설치 없이 `Fiber`, `alias`, `Zlib`, `Marshal.load`, `Regexp`/`MatchData`를 포함한 Ruby 스크립트를 실행합니다.
- **RGSS1(RMXP) & RGSS3(VX Ace) 동시 호환 런타임**: `auto` / `rgss1`(`640×480`, 40fps) / `rgss3`(`544×416`, 60fps) 모드를 지원하며 `Graphics`, `Input`, `Audio`(OGG `LOOPSTART`/`LOOPLENGTH`), `Bitmap`, `Sprite`, `Viewport`, `Plane`, `Window`(1/4인자), `Tilemap`, `Table`, `load_data`, `rgss_main`을 제공합니다.
- **저작권 분리형 사용자 RTP · 스크립트 구조**: 공식 RPG Maker 기본 스크립트(`Game_*`, `Scene_*`, `Window_*`)와 공식 RTP 에셋은 배포판에 포함되지 않으며, 사용자가 보유한 RTP 폴더나 `Scripts.rxdata`/`.rvdata2`를 연결·가져오기해 실행할 수 있습니다.
- **스튜디오 탭 6 (`6. 스크립트 · RGSS`) & 라이브 플레이어**: Ruby 구문 강조 편집기, 안전 Undo & `*` 수정 상태 추적, 사용자 RTP 연결/로컬 자동 감지/목록 비우기(`rtp=` 연결 상태 콘솔 로깅), `▶ mruby VM 헤드리스 테스트`, `🎮 RGSS 스크립트 플레이어 실행`을 지원합니다.
- **CLI 확장**: `scripts` (`list|get|set|add|delete|move|import`) 및 `rgss` (`show|set|check-rtp|run|play`) 명령을 추가했습니다.
- **프로젝트 폴더 열기 수정**: 프로젝트 루트 폴더(`ir/` 상위 폴더)로 스튜디오를 열거나 전환할 때도 해당 프로젝트가 정확히 열리도록 `_resolve_ir_dir()` 및 그래픽 경로 재설정을 반영했습니다.
- **탭 3 애니메이션 이펙트 재생 보완**: 새 프로젝트 기본 `#1: 기본 타격`을 6프레임 실제 모션 데이터로 생성하고, 셀이 비어 있는 기존 스텁 프레임에서도 `▶ 재생` 시 모션 미리보기가 정상 순환하도록 수정했습니다.
- **하단 콘솔 UI 정리**: 테스트 성격의 단축 버튼(`퍼징 100회`, `적 체력 1.2배`)을 제거했습니다.

전체 변경 내역: [CHANGELOG.md](https://github.com/L-Jack-00/RPGCreator/blob/main/CHANGELOG.md)

## 포함 파일 (`RPGCreator-v0.2.0-win64.zip`)
- `RPGCreatorStudio.exe`: Windows용 비주얼 스튜디오 GUI 실행 파일 (`_internal/` 격리 패키징, `native/rpgc_mruby.dll` 및 `rgss_prelude.rb` 포함)
- `_internal/`: 런타임 및 의존 라이브러리 격리 디렉터리 (이동 시 반드시 함께 유지)
- `sample_workspace/`: 바로 열어보고 체험할 수 있는 기본 RMXP + IR 샘플 프로젝트
- `RPGCreatorStudio.ico`: 앱 아이콘 파일
- `README.md`, `CHANGELOG.md`: 사용 안내, CLI 레퍼런스, 변경 내역

## 실행 방법 (Windows)
1. `RPGCreator-v0.2.0-win64.zip`의 압축을 원하는 폴더에 풉니다.
2. 폴더 안의 `RPGCreatorStudio.exe`를 실행합니다. *(`_internal/` 폴더와 같은 위치에 있어야 실행됩니다. 초기 비서명 테스트 빌드이므로 Windows SmartScreen 경고가 표시되면 `추가 정보` → `실행`을 눌러 주세요. 체크섬은 `checksums-v0.2.0.txt`로 검증할 수 있습니다.)*
3. 기본으로 새 빈 프로젝트가 열리며, 샘플을 보려면 `열기 (IR)` → `sample_workspace/ir` 또는 `새 샘플`을 선택하세요. RGSS 스크립트·RTP 연동은 상단 **탭 6 (`6. 스크립트 · RGSS`)**에서 테스트할 수 있습니다.
