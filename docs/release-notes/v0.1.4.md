# RPGCreator `v0.1.4` (Experimental Test Release)

> [!WARNING]
> **실험 단계 테스트 버전 안내**
>
> 본 릴리즈(`v0.1.4`)는 **초기 실험용 테스트 버전**입니다. 일부 에디터 기능, 외부 프로젝트 변환(`MV/MZ`, `VX Ace`, `Tiled`), UI 동작에서 예기치 못한 문제가 발생할 수 있으며 향후 업데이트 과정에서 호환성이나 옵션이 변경될 수 있습니다. 기존 프로젝트 테스트 전 반드시 원본 백업을 보관해 주세요.

## 스튜디오 편집 안정성 및 프로젝트 생명주기 개선

### 새 기능 및 개선 사항
- **기본 빈 프로젝트 실행**: 경로를 지정하지 않고 스튜디오를 실행하면 20×15 빈 맵 1개를 가진 새 빈 프로젝트가 기본적으로 열립니다. 상단 툴바와 `파일` 메뉴에 `빈 프로젝트 (Ctrl+N)`, `💾 저장 (Ctrl+S)`, `다른 이름으로 저장...`을 추가했습니다.
- **수정 상태 표시(`*`)**: 맵·이벤트·데이터베이스·전투 공식·커먼 이벤트·애니메이션·텍스트 편집기에 변경사항이 생기면 창 제목 맨 앞에 `*`가 표시되고, 저장 시 `*`가 해제됩니다.
- **닫기 및 프로젝트 전환 시 저장 확인**: 저장되지 않은 변경사항이 남아 있을 때 창을 닫거나 다른 프로젝트를 열면 `저장 / 저장 안 함 / 취소`를 묻고, `저장 안 함` 선택 시 직전 저장 스냅샷으로 되돌립니다.
- **스크립트·JSON 편집 Undo 보호**: 커먼 이벤트 명령, 애니메이션 JSON, 전투 공식, DB Raw JSON, i18n/블루프린트, 이벤트 명령 편집기에서 초기 텍스트 로드 시 Undo 스택을 분리하고 DSL 삽입을 단일 Undo 단위로 처리해, `Ctrl+Z` 입력 시 기존 텍스트 전체가 사라지지 않도록 개선했습니다.

전체 변경 내역: [CHANGELOG.md](https://github.com/L-Jack-00/RPGCreator/blob/main/CHANGELOG.md)

## 포함 파일 (`RPGCreator-v0.1.4-win64.zip`)
- `RPGCreatorStudio.exe`: Windows용 비주얼 스튜디오 GUI 실행 파일 (`_internal/` 격리 패키징)
- `_internal/`: 런타임 및 의존 라이브러리 격리 디렉터리 (이동 시 반드시 함께 유지)
- `sample_workspace/`: 바로 열어보고 체험할 수 있는 기본 RMXP + IR 샘플 프로젝트
- `RPGCreatorStudio.ico`: 앱 아이콘 파일
- `README.md`, `CHANGELOG.md`: 사용 안내, CLI 레퍼런스, 변경 내역

## 실행 방법 (Windows)
1. `RPGCreator-v0.1.4-win64.zip`의 압축을 원하는 폴더에 풉니다.
2. 폴더 안의 `RPGCreatorStudio.exe`를 실행합니다. *(`_internal/` 폴더와 같은 위치에 있어야 실행됩니다. 초기 비서명 테스트 빌드이므로 Windows SmartScreen 경고가 표시되면 `추가 정보` → `실행`을 눌러 주세요. 체크섬은 `checksums-v0.1.4.txt`로 검증할 수 있습니다.)*
3. 기본으로 새 빈 프로젝트가 열리며, 샘플을 보려면 `열기 (IR)` → `sample_workspace/ir` 또는 `새 샘플`을 선택하세요.
