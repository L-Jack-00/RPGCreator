# RPGCreator `v0.1.3` (Experimental Test Release)

> [!WARNING]
> **실험 단계 테스트 버전 안내**
>
> 본 릴리즈(`v0.1.3`)는 **초기 실험용 테스트 버전**입니다. 일부 에디터 기능, 외부 프로젝트 변환(`MV/MZ`, `VX Ace`, `Tiled`), UI 동작에서 예기치 못한 문제가 발생할 수 있으며 향후 업데이트 과정에서 호환성이나 옵션이 변경될 수 있습니다. 기존 프로젝트 테스트 전 반드시 원본 백업을 보관해 주세요.

## 애니메이션 재생 수정

이번 버전은 애니메이션 미리보기·저장·게임 내 재생 문제를 고친 버그 수정 릴리즈입니다.

### 스튜디오 (탭 3 · 애니메이션 에디터)
- **`▶ 재생`이 실제 애니메이션을 재생합니다**: 이전에는 시트 패턴 번호만 차례로 보여줬습니다. 이제 프레임마다 모든 셀의 패턴·위치·배율·회전·반전·투명도·가산/감산 합성을 반영해 RMXP와 같은 20fps로 재생합니다. JSON 창에서 저장 전에 고친 내용도 바로 미리 볼 수 있고, 미리보기 창은 160px로 커졌습니다.
- **`애니메이션 저장`이 정상 동작합니다**: 버튼을 누르면 항상 오류가 나던 문제와, 저장 시 기존 프레임·타이밍이 기본값으로 덮어써지던 문제를 고쳤습니다.
- 같은 원인으로 실패하던 탭 4의 **i18n 적용** 버튼도 고쳤습니다.

### 게임 플레이어
- 대상이 **"이 이벤트"**인 애니메이션 표시가 주인공 위에 나오던 문제를 고쳤습니다.
- 재생 속도를 RMXP(20fps)에 맞추고, 표시 위치(위·가운데·아래·화면)와 가산 합성을 반영합니다.
- 전투 애니메이션이 길이와 상관없이 약 12프레임에서 잘리던 문제를 고쳤습니다.

### 데이터 · CLI
- 셀이 여러 개인 프레임이 RMXP와 다른 순서로 기록되던 문제를 고쳤습니다.
- `pack`으로 내보낼 때 새로 만든 애니메이션이 `RPG::Animation` 객체가 아닌 Hash로 저장되던 문제를 고쳤습니다.
- `anim set --cells-json`이 프레임별 배열(`[[셀, ...], [셀]]`)을 반영합니다.

> v0.1.2 이전 버전의 스튜디오나 `anim set`으로 셀이 여러 개인 애니메이션을 만들었다면 셀 배치가 어긋나 있을 수 있습니다. 해당 애니메이션을 다시 저장해 주세요.

전체 변경 내역: [CHANGELOG.md](https://github.com/L-Jack-00/RPGCreator/blob/main/CHANGELOG.md)

## 포함 파일 (`RPGCreator-v0.1.3-win64.zip`)
- `RPGCreatorStudio.exe`: Windows용 비주얼 스튜디오 GUI 실행 파일 (`_internal/` 격리 패키징)
- `_internal/`: 런타임 및 의존 라이브러리 격리 디렉터리 (이동 시 반드시 함께 유지)
- `sample_workspace/`: 바로 열어보고 플레이테스트할 수 있는 기본 RMXP + IR 샘플 프로젝트
- `RPGCreatorStudio.ico`: 앱 아이콘 파일
- `README.md`, `CHANGELOG.md`: 사용 안내, CLI 레퍼런스, 변경 내역

## 실행 방법 (Windows)
1. `RPGCreator-v0.1.3-win64.zip`의 압축을 원하는 폴더에 풉니다.
2. 폴더 안의 `RPGCreatorStudio.exe`를 실행합니다. *(초기 비서명 테스트 빌드이므로 Windows SmartScreen 경고가 표시되면 `추가 정보` → `실행`을 눌러 주세요. 체크섬은 `checksums-v0.1.3.txt`로 검증할 수 있습니다.)*
3. 기본 샘플 프로젝트가 열리면 상단의 **`▶ 플레이테스트 (F6)`**로 즉시 게임을 체험할 수 있습니다.
