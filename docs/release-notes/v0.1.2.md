# RPGCreator `v0.1.2` (Experimental Test Release)

> [!WARNING]
> **실험 단계 테스트 버전 안내**
>
> 본 릴리즈(`v0.1.2`)는 **초기 실험용 테스트 버전**입니다. 일부 에디터 기능, 외부 프로젝트 변환(`MV/MZ`, `VX Ace`, `Tiled`), UI 동작에서 예기치 못한 문제가 발생할 수 있으며 향후 업데이트 과정에서 호환성이나 옵션이 변경될 수 있습니다. 기존 프로젝트 테스트 전 반드시 원본 백업을 보관해 주세요.

## 새 기능: 스튜디오에서 전투 공식 선택

**탭 2(데이터베이스 · 밸런스) → `⚔ 전투 공식`** 하위 탭에서 프로젝트의 전투 데미지 공식을 바꿀 수 있습니다.

- **프리셋 선택**: `rmxp`(기본값), `simple`(v0.1.0 방식), `rm2k`, `rm2k3`, `rmvx`, `rmvxace`, `rmmv`, `rmmz` 중에서 고르고, 설명과 기본 공식을 바로 확인
- **공식 직접 입력**: 일반 공격·스킬 공식(`a.atk * 4 - b.def * 2`, `Math.max(...)` 등)과 치명타 배율, 분산, 방어 시 나누기, 나눗셈 방식, 능력치 모델을 덮어쓰기 (비워 두면 프리셋 기본값)
- **저장 전 검사**: 문법 오류나 잘못된 숫자는 저장하지 않고 오류로 표시
- **프리셋별 예상 데미지 비교**: 적과 주인공 스킬을 골라 모든 프리셋과 아직 저장하지 않은 입력값의 데미지, 승리·패배까지 타수를 한 표로 비교
- **적용과 되돌리기**: 적용하면 실행 취소 기록이 남고(`Ctrl+Z`), 오른쪽 밸런스 검증 결과가 새 공식으로 다시 계산됩니다. 콘솔 명령으로 바꿔도 화면이 따라 갱신됩니다.

v0.1.1에서 추가된 프로젝트별 전투 공식(기본값 RPG Maker XP 공식)에 대한 설명은 [v0.1.1 릴리즈](https://github.com/L-Jack-00/RPGCreator/releases/tag/v0.1.1)를 참고하세요.

전체 변경 내역: [CHANGELOG.md](https://github.com/L-Jack-00/RPGCreator/blob/main/CHANGELOG.md)

## 포함 파일 (`RPGCreator-v0.1.2-win64.zip`)
- `RPGCreatorStudio.exe`: Windows용 비주얼 스튜디오 GUI 실행 파일 (`_internal/` 격리 패키징)
- `_internal/`: 런타임 및 의존 라이브러리 격리 디렉터리 (이동 시 반드시 함께 유지)
- `sample_workspace/`: 바로 열어보고 플레이테스트할 수 있는 기본 RMXP + IR 샘플 프로젝트
- `RPGCreatorStudio.ico`: 앱 아이콘 파일
- `README.md`, `CHANGELOG.md`: 사용 안내, CLI 레퍼런스, 변경 내역

## 실행 방법 (Windows)
1. `RPGCreator-v0.1.2-win64.zip`의 압축을 원하는 폴더에 풉니다.
2. 폴더 안의 `RPGCreatorStudio.exe`를 실행합니다. *(초기 비서명 테스트 빌드이므로 Windows SmartScreen 경고가 표시되면 `추가 정보` → `실행`을 눌러 주세요. 체크섬은 `checksums-v0.1.2.txt`로 검증할 수 있습니다.)*
3. 기본 샘플 프로젝트가 열리면 상단의 **`▶ 플레이테스트 (F6)`**로 즉시 게임을 체험할 수 있습니다.
