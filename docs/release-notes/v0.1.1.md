# RPGCreator `v0.1.1` (Experimental Test Release)

> [!WARNING]
> **실험 단계 테스트 버전 안내**
>
> 본 릴리즈(`v0.1.1`)는 **초기 실험용 테스트 버전**입니다. 일부 에디터 기능, 외부 프로젝트 변환(`MV/MZ`, `VX Ace`, `Tiled`), UI 동작에서 예기치 못한 문제가 발생할 수 있으며 향후 업데이트 과정에서 호환성이나 옵션이 변경될 수 있습니다. 기존 프로젝트 테스트 전 반드시 원본 백업을 보관해 주세요.

> [!IMPORTANT]
> **기본 전투 공식이 바뀌었습니다.** v0.1.1부터 데미지 계산의 기본값이 **RPG Maker XP 공식**입니다. v0.1.0에서 만든 프로젝트는 전투 난이도가 달라질 수 있습니다. 예전 방식을 유지하려면 프로젝트마다 다음을 실행하세요.
> ```
> python run_app.py battle-formula set <ir_dir> --preset simple
> ```

## 새 기능
- **프로젝트별 전투 데미지 공식**: `ir_project.json`의 `battle_formula`로 프로젝트마다 계산 방식을 고를 수 있습니다. 플레이어·`sim`·`balance-check`가 모두 같은 설정을 따릅니다.

  | 프리셋 | 일반 공격 기본식 | 치명타 |
  |---|---|---|
  | `rmxp` (기본값) | `max(ATK - PDEF/2, 0) × (20 + STR) / 20` | ×2 |
  | `simple` | v0.1.0 단순 공식 | ×1.5 |
  | `rm2k`, `rm2k3` | `ATK/2 - DEF/4` | ×3 |
  | `rmvx` | `ATK×4 - DEF×2` | ×3 |
  | `rmvxace`, `rmmv`, `rmmz` | `a.atk * 4 - b.def * 2` | ×3 |

  - RPG Maker 스타일 공식 직접 지정(`Math.max(...)` 등), 스킬별 `damage_formula`
  - 새 CLI `battle-formula list / show / set / calc` (`calc --all-presets`로 프리셋별 데미지 비교)
- **Claude Code 연동 가이드(`CLAUDE.md`)** 및 스튜디오 콘솔의 **외부 AI CLI 연결 안내** 추가

## 버그 수정
- `balance-check`가 주인공 능력치를 잘못 읽어 HP 1로 시뮬레이션하던 문제 (모든 전투가 1턴에 끝나고 샘플 보스 승률이 0%로 나오던 증상)
- 외부 AI CLI에 `{prompt}`로 프롬프트를 넘길 때 따옴표·백틱·줄바꿈 때문에 명령이 깨지거나 셸이 명령을 실행할 수 있던 문제

## 기타 변경
- 샘플 프로젝트의 적 수치를 RMXP 공식에 맞춰 조정 (고블린 STR 18→10, 고블린 대장 HP 240→180 / ATK 32→22 / STR 32→10)

전체 변경 내역: [CHANGELOG.md](https://github.com/L-Jack-00/RPGCreator/blob/main/CHANGELOG.md)

## 포함 파일 (`RPGCreator-v0.1.1-win64.zip`)
- `RPGCreatorStudio.exe`: Windows용 비주얼 스튜디오 GUI 실행 파일 (`_internal/` 격리 패키징)
- `_internal/`: 런타임 및 의존 라이브러리 격리 디렉터리 (이동 시 반드시 함께 유지)
- `sample_workspace/`: 바로 열어보고 플레이테스트할 수 있는 기본 RMXP + IR 샘플 프로젝트
- `RPGCreatorStudio.ico`: 앱 아이콘 파일
- `README.md`, `CHANGELOG.md`: 사용 안내, CLI 레퍼런스, 변경 내역

## 실행 방법 (Windows)
1. `RPGCreator-v0.1.1-win64.zip`의 압축을 원하는 폴더에 풉니다.
2. 폴더 안의 `RPGCreatorStudio.exe`를 실행합니다. *(초기 비서명 테스트 빌드이므로 Windows SmartScreen 경고가 표시되면 `추가 정보` → `실행`을 눌러 주세요. 체크섬은 `checksums-v0.1.1.txt`로 검증할 수 있습니다.)*
3. 기본 샘플 프로젝트가 열리면 상단의 **`▶ 플레이테스트 (F6)`**로 즉시 게임을 체험할 수 있습니다.
